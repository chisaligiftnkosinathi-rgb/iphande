# iPhande Media Album

This folder is reserved for the real iPhande media album audio files, story tracks, and calibration audio artifacts.

- Place all official album tracks, spoken word, and calibration audio here.
- Each file should be named according to the tracklist and story structure in the MEDIA_SYSTEM_CALIBRATION_ALBUM_iphande_story.md.
- This folder is the canonical source for the iPhande audio memory and continuity archive.

Example filenames:
- 01_Dreams_Bigger_Than_Home.wav
- 02_The_People_Who_Were_Hidden.wav
- 03_Algorithms_Dont_Know_My_Mother.wav
- ...
- 10_Continuity.wav

Add new tracks as the project evolves. This folder is the living memory of the iPhande story album.
