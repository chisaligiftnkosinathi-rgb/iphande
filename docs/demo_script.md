# iPhande Demo Script

## Purpose

A step-by-step guide for demonstrating iPhande’s core flows, values, and differentiators. Use for presentations, interviews, onboarding, and showcases.

- Name: Gift Chisali

## Demo Flow

### 1. Splash Screen
- Show iPhande logo and tagline: “Visibility with Dignity”

### 2. Login / Guest
- Enter as guest or demo user

### 3. Create Profile
- Fill in name, business, area, contact
- Emphasize privacy: only area, not exact address

### 4. Home Dashboard
- Show profile summary, opportunities, and actions

### 5. Generate Visibility Post
- Select business line: “funeral_cover”
- Enter offer: “Affordable funeral cover from R47 per month”
- Generate post
- Show WhatsApp/Facebook share links
- Emphasize: user reviews before sharing

### 6. Opportunities
- Create a new opportunity
- Assign to profile

### 7. Opportunity Replay Timeline
- Add timeline events (e.g., “Customer called”, “Follow-up scheduled”)
- Show replay of opportunity progression

### 8. Follow-Ups
- Schedule a follow-up
- Mark as complete

### 9. Public Profile Preview
- Show public profile as seen by others
- Emphasize privacy boundaries

### 10. Reflection Screen
- Add a daily reflection or scripture encouragement

---

## Key Talking Points
- Visibility without spam or manipulation
- Replay and continuity for every opportunity
- Privacy and dignity for all users
- Designed for township, informal, and commission-based businesses
- Ethical, reviewable content generation
