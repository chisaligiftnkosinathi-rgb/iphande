# Wisdom Library Doctrine

## Purpose
Preserve principles, not personalities.

## Core Pattern
Problem -> Principle -> Evidence -> Outcome

## Three Categories
1. Purpose
2. System
3. Execution

## Rule
No principle is trusted because a famous person said it.
A principle becomes trusted when it is observed, tested, and evidenced.
