# IPHANDE VISUAL REVIEW PROTOCOL

## Purpose
To ensure every image in the archive is emotionally, spiritually, and canonically aligned before being accepted as canonical or archival.

---

## Review Steps
1. Place all new visual generations in the `drafts/` folder for the relevant track.
2. Review each image using the following criteria:

### Emotional Alignment
- Does this feel human?
- Does this preserve dignity?
- Does this feel spiritually calm?
- Does this avoid spectacle?

### Canon Alignment
- Does this align with the album doctrine?
- Does this preserve continuity?
- Does this match the emotional phase of the track?

### Visual Integrity
- Is the composition emotionally truthful?
- Does the lighting support the atmosphere?
- Is the imagery grounded rather than artificial?

3. Move images that pass all criteria to `selected/`.
4. Move images that do not pass to `rejected/` (with a note in `review_notes/`).
5. For each selected image, add a short review note in `review_notes/` explaining why it was chosen.
6. Only after review, promote one image to canonical status for the track.

---

## Reviewer’s Oath
I will preserve the emotional and spiritual continuity of the archive above all technical or commercial considerations.
