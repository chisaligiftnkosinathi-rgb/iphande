# DSP Release Checklist

For every digital streaming platform (DSP) release, verify:
- WAV export verified
- Metadata complete
- Cover art compliant
- AI disclosure reviewed
- ISRC assigned
- Artist naming consistent
- Release description finalized
- Theology review completed
- Canon alignment verified

Platforms: Spotify, Apple Music, YouTube Music, Deezer, TikTok audio, Instagram audio

This checklist is the final release gate for every track.
