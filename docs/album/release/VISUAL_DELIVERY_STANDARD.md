# Visual Delivery Standard

- Spotify cover: 3000x3000px, JPG/PNG, no text overlays
- YouTube thumbnail: 1280x720px, cinematic stills
- Vertical reels: 1080x1920px, portrait orientation
- Cinematic posters: high-res, minimal branding
- Typography: consistent, legible, on-brand
- Export formats: PNG for art, JPG for web, MP4 for video

All visuals must meet platform specs and preserve the album’s visual identity.
