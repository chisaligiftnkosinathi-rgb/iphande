# Archive Structure

Defines folder naming, export standards, and backup protocols:

- Folder naming: IPH-TRACKNUMBER-TITLE
- Export standards: MP3, WAV, stems, prompts, cover art
- Metadata: Suno version, generation date, authorship
- Backups: Local, cloud, offline copies
- Artwork: Stored with track archive

This structure prevents chaos and preserves continuity.
