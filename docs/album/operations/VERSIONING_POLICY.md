# Versioning Policy

Tracks may evolve over time. This document defines versioning and lineage:

- v1: Original release
- remaster: Improved mix/master
- cinematic edition: Extended or reimagined version
- acoustic edition: Stripped-down version
- live narration edition: Live or alternate performance

Example lineage:
IPH-001-v1
IPH-001-v2-remaster
IPH-001-live-cut

All versions must be archived and documented for continuity.
