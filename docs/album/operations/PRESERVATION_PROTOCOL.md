# Preservation Protocol

To ensure long-term continuity and protection of the iPhande album, follow these preservation steps:

- Local backups: Maintain up-to-date local copies of all tracks, stems, prompts, and metadata.
- Cloud backups: Store encrypted copies in secure cloud storage.
- Export duplication: Keep multiple export formats (MP3, WAV, stems, artwork).
- Metadata preservation: Archive Suno version, generation timestamps, authorship, and all creative decisions.
- Checksum strategy: Use checksums to verify file integrity over time.
- Offline archive copies: Store physical backups (external drives, USBs) in safe locations.

This protocol is critical for future continuity, recovery, and stewardship of the album’s memory.
