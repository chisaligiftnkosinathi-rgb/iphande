# Visual Direction — Track 06

Visual themes:
- Quiet rooms
- Hands holding head in reflection
- Dim lighting
- Empty corridors
- Faded journals
- Clocks ticking slowly
- Prayerful posture
- Subtle signs of fatigue
- Unfinished letters
- Windows with rain
- Shadows on walls

Avoid:
- Over-dramatic suffering
- Rage or collapse imagery
- Heroic struggle visuals
- Commercialized pressure

The emotional visual language should feel: quiet fear, internal reflection, and spiritual honesty.
