# Visual Direction — Track 09

Visual themes:
- sunrise over communities
- people gathering
- hands building together
- elders and children
- memory walls
- gentle wind moving through streets
- faces illuminated by morning light
- communal meals
- hands passing stories
- soft blue and gold tones
- expansive landscapes

Avoid:
- branding or product imagery
- corporate symbolism
- ego-centered visuals
- over-glossed perfection

The emotional visual language should feel: the hidden purpose finally becoming visible.
