# Visual Direction — Track 10

Visual themes:

* grandparents and children
* notebooks passed between hands
* fading photographs
* builders teaching younger generations
* old tools beside modern systems
* sunrise over landscapes
* archives protected carefully
* footsteps across generations
* hands planting seeds
* warm earth textures
* intergenerational memory

Avoid:

* apocalypse imagery
* futuristic domination visuals
* “legacy empire” aesthetics
* cold institutional archive imagery

The emotional visual language should feel:

human wisdom carried forward with care
