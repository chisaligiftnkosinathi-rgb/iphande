# Visual Direction — Track 07

Visual themes:
- dawn after rain
- quiet prayer spaces
- open windows
- soft sunlight through dust
- notebooks resting closed
- hands lifted quietly
- walking slowly through empty streets
- calm skies after storms
- warm earth tones
- stillness
- healing silence

Avoid:
- flashy religious imagery
- dramatic miracle aesthetics
- performance spirituality
- superiority imagery

The emotional visual language should feel: peace returning after pressure.
