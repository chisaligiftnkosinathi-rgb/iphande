# Visual Direction — Track 05

Visual themes:
* old photographs
* notebooks
* cassette tapes
* archived letters
* fading handwriting
* family memories
* dusty shelves
* preserved documents
* train stations
* footsteps
* wind moving through empty spaces
* warm analog textures
* dim golden lighting

Avoid:
* futuristic data visualization clichés
* cold sci-fi archive aesthetics
* cyberpunk memory visuals

The emotional visual language should feel: human memory preserved with care.
