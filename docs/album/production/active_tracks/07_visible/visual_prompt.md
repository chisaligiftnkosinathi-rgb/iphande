# Visual Direction — Track 08

Visual themes:
- sunrise light
- smiling ordinary people
- marketplaces alive with warmth
- builders standing proudly
- teachers in classrooms
- mothers laughing softly
- community gatherings
- children running through morning light
- hands helping each other
- soft golden tones
- healing human presence

Avoid:
- fame aesthetics
- influencer culture imagery
- luxury symbolism
- over-glossed AI perfection

The emotional visual language should feel: gentle restoration of human dignity.
