# Visual Direction — Track 11

Visual themes:
- luminous landscapes
- children looking toward the horizon
- hands passing stories across generations
- faces illuminated by soft light
- memory objects preserved
- sunrise and sunset transitions
- communal rituals
- sacred landscapes
- echoes of legacy
- soft gold and blue tones
- timeless, peaceful imagery

Avoid:
- fame or celebrity imagery
- cold institutional archive imagery
- over-glossed perfection

The emotional visual language should feel: hope and humanity carried forward with care.
