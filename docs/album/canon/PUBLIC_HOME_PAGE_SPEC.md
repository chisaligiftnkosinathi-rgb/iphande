# Public Home Page Specification

## Purpose
Create an outer home page (landing page) accessible before authentication. It should explain iPhande simply and clearly.

## Core Message
> "iPhande helps local people be seen, find work, post opportunities, and preserve proof of work."

## Required Sections
1. **Hero:** Welcoming statement and primary calls to action.
2. **What iPhande Does:** Simple explanation of the platform.
3. **For Stewards:** Value proposition for those doing the work.
4. **For Customers:** Value proposition for those seeking services.
5. **Community Opportunities:** Preview of available local work/needs.
6. **Sponsored / Advertisements:** Visibility for local businesses.
7. **How It Works:** Step-by-step simple guide.
8. **Sign In / Register:** Bottom call to action.

## Main Buttons / CTAs
- **Join Free**
- **Post Opportunity**
- **Find Local Services**
- **Sign In**

## Design Philosophy
Keep it grounded, honest, and mobile-friendly. Avoid overly corporate or "tech-startup" jargon. Speak directly to the community.
