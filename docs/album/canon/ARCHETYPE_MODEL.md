# iPhande Archetype Model

This document formally defines the Archetypes used within the iPhande platform.

While a **Lineage** defines the *economic reality* (how value flows), an **Archetype** defines the *operating style* (how the steward naturally operates). These two concepts remain completely independent.

## Core Archetypes

*   **BUILDER**
    Creates and delivers.

*   **CONNECTOR**
    Connects people and opportunities.

*   **SHEPHERD**
    Supports and cares for people.

*   **ARCHITECT**
    Designs systems and structures.

*   **TEACHER**
    Transfers knowledge.

*   **EXPLORER**
    Discovers opportunities and information.

*   **OPERATOR**
    Runs and maintains processes.

*   **CREATOR**
    Produces content, media, or creative work.
