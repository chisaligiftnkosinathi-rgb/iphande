# Vocal Identity Guide

- Narrator tone: grounded, sincere, reflective
- Child voice: innocence, future, memory
- Choir: communal memory, spiritual depth
- Spoken-word: cinematic pacing, emotional restraint
- Pronunciation: clear, African linguistic texture
- Emotional restraint: avoid melodrama, keep sincerity

This guide ensures vocal consistency and authenticity, especially for AI-assisted generation.
