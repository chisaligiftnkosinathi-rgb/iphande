# Core Symbolism

This document defines the recurring symbolic language of the iPhande album. These symbols must remain consistent across lyrics, visuals, videos, covers, and trailers.

- **Dust**: origin, human reality
- **Roads**: journey, calling
- **Light**: revelation, hope
- **Taxis**: movement, survival
- **Notebooks**: ideas, building
- **Rain**: renewal
- **Children**: future continuity
- **Marketplaces**: human visibility
- **Night coding**: unseen building

These symbols are the visual and emotional anchors of the iPhande world.
