# File Naming Standard

All files must follow a consistent naming convention:

IPH-TRACKNUMBER_title_version.ext

Examples:
IPH-001_dreams_bigger_than_home_v1.wav
IPH-001_dreams_bigger_than_home_MASTER.wav
IPH-001_cover_v2.png
IPH-001_suno_prompt.txt

Consistency in naming prevents archival confusion and supports long-term continuity.
