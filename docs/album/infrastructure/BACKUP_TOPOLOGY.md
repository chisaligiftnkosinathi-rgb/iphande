# Backup Topology

Defines the backup and preservation strategy:

- Local backups: Working copies on primary machines
- Cloud mirrors: Encrypted cloud storage for redundancy
- Offline archives: External drives, USBs, or physical media
- Release mirrors: Copies of all distributed versions
- Checksum verification: Regular integrity checks
- Preservation cadence: Scheduled backup and verification

This topology aligns with the continuity doctrine and protects against data loss.
