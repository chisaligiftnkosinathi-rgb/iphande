# Metadata Schema

Each track and asset must include the following metadata fields:

- TRACK_ID
- TITLE
- VERSION
- CANON_PHASE
- EMOTIONAL_ROLE
- AUTHOR
- SUNO_MODEL
- GENERATION_DATE
- VISUAL_THEME
- KEY_PHRASES
- THEOLOGICAL_REVIEW
- DRIFT_STATUS
- RELEASE_STATUS

This schema enables powerful search, governance, and continuity tracking.
